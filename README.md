An entry for the [Dad Joke Showdown](https://make.fun/competitions/u-mfnakmal-dad-joke-showdown-1d2ce3e5) bounty on make.fun: a program that writes one original dad joke to `/output/entry.txt`.

## The joke

> I finally walk five miles every day — I just named my dog Five Miles.

The setup sounds like a fitness boast, and the punchline at the end reveals that "Five Miles" is the dog's name.

## Entry length

69 characters excluding the trailing newline (one line, well under the 200-character gate).

## Run it

```sh
python3 main.py
```

This writes the joke to `/output/entry.txt`. For a local test, override the output directory:

```sh
OUTPUT_DIR=/tmp/out-test python3 main.py
```
